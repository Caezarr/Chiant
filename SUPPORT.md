# Support

## Statut du projet

**Boring (Chiant) est en pre-alpha**. Le code et le produit sont en développement actif et ne sont pas encore prêts pour une utilisation en production.

## Obtenir de l'aide

### Bugs et demandes de fonctionnalités

Pour signaler un bug ou demander une nouvelle fonctionnalité, ouvre une issue sur GitHub :

👉 [GitHub Issues](https://github.com/Caezarr/Chiant/issues)

Utilise les templates disponibles dans `.github/ISSUE_TEMPLATE/` pour structurer ton rapport.

### Vulnérabilités de sécurité

**Ne signale JAMAIS une vulnérabilité de sécurité via une issue publique.**

Consulte [SECURITY.md](SECURITY.md) pour les instructions de signalement confidentiel, ou contacte directement :

- Email : `gabriel@meetwonka.com` (sujet préfixé `[SECURITY]`)
- GitHub Security Advisory : https://github.com/Caezarr/Chiant/security/advisories/new

### Questions générales

Pour les questions d'ordre général sur le projet, tu peux :

- Ouvrir une [Discussion GitHub](https://github.com/Caezarr/Chiant/discussions)
- Consulter la documentation dans le répertoire `docs/`
- Lire le [README.md](README.md) pour une vue d'ensemble

## Contribuer

Si tu souhaites contribuer au projet, consulte les ressources suivantes :

- [CONTRIBUTING.md](CONTRIBUTING.md) pour les guidelines de contribution
- [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) pour le code de conduite
- [CODEOWNERS](CODEOWNERS) pour les responsables de chaque partie du code
