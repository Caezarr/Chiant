# Support

## Getting Help

### Bug Reports
For bugs or feature requests, please open an issue:  
👉 [GitHub Issues](https://github.com/Caezarr/Chiant/issues)

Use the templates in `.github/ISSUE_TEMPLATE/` to structure your report.

### Security Vulnerabilities
**Never report security vulnerabilities via public issues.**  
See [SECURITY.md](SECURITY.md) for confidential reporting instructions.

### General Questions
For general questions about using the CLI or notebooks:
- Open a [GitHub Discussion](https://github.com/Caezarr/Chiant/discussions)
- Check the documentation in the `docs/` directory
- Read the [README.md](README.md) for an overview
